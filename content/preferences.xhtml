中文标题与摘要

在条目信息面板新增「中文标题」「中文摘要」两个分区，条目打开时可自动翻译并填入。译文保存在条目的「其他（Extra）」字段中，可随 Zotero 同步。

翻译服务

大模型 API（OpenAI 兼容）

支持 DeepSeek、硅基流动、Moonshot、OpenAI、Ollama 等任何兼容 /chat/completions 的服务。Base URL 例：https://api.deepseek.com

DeepL API

MyMemory

Google 翻译

使用 translate.googleapis.com 的免费接口，无需配置。若所在网络无法访问 Google，请改用「大模型 API」。

PDF 引擎（真正保留原版面）

在阅读器浮条点「生成双语PDF」时，调用开源引擎 BabelDOC（沉浸式翻译官方开源后端）/ PDFMathTranslate 生成新的双语 PDF：图表公式不动，译文按原文框重排、字号自适应。安装命令：uv tool install --python 3.12 --with "bitstring<5" BabelDOC

PDF 双语对照

阅读 PDF 时，点阅读器工具栏的「双语对照」按钮，即以原位覆盖或重排方式显示中文译文；每段右上角的 × 可单独取消该段翻译，浮动工具条可停止 / 清除 / 关闭，并可拖动、选择翻译页数。
