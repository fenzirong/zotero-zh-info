把英文文献的中文标题与中文摘要写进条目信息面板，并可对 PDF 生成保留原版面的双语版本。配置保存在本机，可随 Zotero 同步。

一、条目信息面板

在条目右侧信息面板新增「中文标题」「中文摘要」两个分区；译文写入条目的「其他（Extra）」字段。

二、翻译服务

下方只显示当前服务的设置

大模型 API（OpenAI 兼容）

支持 DeepSeek、硅基流动、Moonshot、OpenAI、Ollama 等任何兼容 /chat/completions 的服务。PDF 引擎也复用这里的配置。

DeepL API

MyMemory

Google 翻译

使用 translate.googleapis.com 的免费接口，无需配置。网络无法访问 Google 时请改用「大模型 API」。

三、PDF 引擎（真正保留原版面）

阅读器浮条点「生成双语PDF」时，插件调用开源引擎（BabelDOC / PDFMathTranslate）重新排版生成新的双语 PDF：图表公式不动、译文按原文框自适应字号，完成后作为子附件挂到该文献下。

推理型模型会把 token 全用在思考上，引擎拿不到正文

uv tool install --python 3.12 --with "bitstring<5" BabelDOC

pdf2zh 还需补钉两个依赖版本，详见 README「pdf2zh 安装」。

四、PDF 双语对照（阅读器内）

不生成新 PDF，直接在阅读器里给译文：每段右上角的 × 可单独取消该段；浮动工具条可拖动、可停可清、可选翻译页数。
